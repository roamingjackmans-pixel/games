# Dungeon Joe — Decisions

**This file is the history**: every decision in the order it was made, with its reason, so nothing is re-litigated
and every rule can be traced. Many later decisions change or reverse earlier ones, so an entry here is not
necessarily how the game works today. **The current reference is [GAME_DESIGN.md](GAME_DESIGN.md)** (rules and
formulas) together with the CONTENT docs (enemies, items, spells, classes) and DATA_MODEL / PROCGEN / NETCODE /
ART_AUDIO; they cite these ids. The first decisions were made on 2026-11-02 in the design session (the owner answered
multiple-choice rounds). Add new decisions at the bottom with the next number, and update GAME_DESIGN.md with them.

## Decisions

| # | Area | Decision | Why |
|---|---|---|---|
| D1 | Genre | Souls-like action RPG (Dark Souls, Salt and Sanctuary) that *plays* like The Binding of Isaac, Diablo 3 and Hades: top-down arena rooms, procedurally generated map, loot rain, cooldown skills. | Owner's brief. |
| D2 | Perspective | Top-down, room-sized arenas (one screen per room, no scrolling camera). | Boss patterns that "cover the map" read clearly; co-op shares one screen; simplest proc-gen. |
| D3 | Death | Souls-style. Character, gear and level persist. Respawn at the last bonfire rested at; zone enemies respawn; unspent Shards drop where you died and can be recovered once. The map seed persists for the whole playthrough; a new map is rolled for a new character or a new NG+ cycle. | Owner wants persistent characters, NG+ and multiple save files. |
| D4 | Co-op | Online co-op from the first release, up to 4 players, browser-to-browser over WebRTC, **host authoritative**. | Owner's choice. |
| D5 | Signaling | **Trystero** (serverless signaling through public Nostr / MQTT / BitTorrent relays), join by 6-character room code. No server to host. | Static GitHub Pages hosting cannot run a signaling server. |
| D6 | Stack | **Vite + TypeScript (strict)**, Canvas 2D, no framework, no game engine library. `npm run build` → `dist/` deployed by GitHub Actions to GitHub Pages. | Types and unit tests matter for a codebase this size; static output. |
| D7 | Hosting | GitHub Pages, project site `DungeonJoe`, served at `https://josephjackman.com/DungeonJoe/`. Vite `base: '/DungeonJoe/'`. **Superseded by D48** (`/games/dungeonjoe/`, repo `games`). | Owner's hosting. |
| D8 | Art | Code-drawn vector art: every entity, weapon and effect drawn with canvas paths, gradients, glow and particles. No sprite assets. | No artist; every enemy still gets a distinct readable silhouette and color; swappable later. |
| D9 | Aiming | Twin-stick: WASD / left stick to move, mouse / right stick to aim. Left click = attack, right click = block. Gamepad gets aim assist. | Owner's choice. |
| D10 | Run length | 7 zones + a final zone (8 bosses). | Owner's choice. |
| D11 | Blocking | Off-hand slot holds a shield, a staff or a talisman. Shields block with right click; small/medium shields can parry. **Anything can be two-handed** (Shift): two-handing gives ×1.5 Bonk/Slicey scaling, disables the off-hand, and lets you guard with the weapon at much higher stamina cost and much lower reduction. Shields have individual block values and block **physical far better than non-physical** damage. | Owner's choice (Souls tradeoff plus two-handing). |
| D12 | Co-op death | A dead player becomes a crawling ghost for 30 s. Teammates revive by **attacking the ghost**: each hit adds that weapon class's revive value until the requirement is met; spells are poor at it. Requirement doubles each time that player is downed between bonfire rests, max ×4 (Elden Ring Nightreign). Revived at 40% HP. If everyone is down the party wipes and respawns at the bonfire. Mimic bites down you instead of killing outright in co-op. | Owner's choice. |
| D13 | Audio | Synthesized with the Web Audio API (no files). | No assets; swappable later. |
| D14 | Tone | Grim world, cheeky text. Dungeons and bosses are serious; item names, stat names (Bonk, Slicey) and flavor text are dry and funny. Joe is an ordinary guy in over his head. | Owner's choice. |
| D15 | Party size | 4 (host + 3). Enemy and boss HP ×(1 + 1.5 × extra players): 2.5×, 4×, 5.5×. | Owner's brief. |
| D16 | Difficulty | One difficulty. NG+ cycles scale enemies and loot, no cap. | Souls-faithful. |
| D17 | Meta progress | Nothing carries between save files. A save file = one character, its gear, map seed and NG+ cycle. 10 slots. Export/import as a JSON file. | Owner's choice. |
| D18 | Leveling | Enemies drop **Shards**. Level up at bonfires only; cost rises per level. A rare **Tear of Undoing** (boss drop / rare chest) redistributes all stats once. | Owner's choice. |
| D19 | Parry | Bucklers and medium shields parry (tap block as a normal attack lands): enemy staggers 2 s, next hit is a ×3 riposte. Greatshields cannot parry. Red (unblockable) attacks cannot be parried. | Owner's choice. |
| D20 | Shops | **Both**: every bonfire has a shop tab (sell gems and gear for Glowen; buy throwables, gem re-rolls, one rotating gear piece at the zone's level). **And** a rare wandering-merchant room appears in some zones selling random special things. Spells are never sold. | Owner's choice. |
| D21 | Combat extras | Elemental damage types (Physical, Fire, Frost, Lightning, Holy, Void) with statuses (Burn, Chill, Shock, Bleed, Poison); Elite enemies with visible modifiers; throwables/consumables on a quick-use key. **No** weapon durability. | Owner's choice. |
| D22 | Zones | 1 Mossy Crypt · 2 Fungal Caverns · 3 Drowned Sewers · 4 Hollow Forest · 5 Ashen Forge · 6 Frozen Reliquary · 7 Clockwork Citadel · 8 The Abyss (final, 3-phase boss). | Owner approved the proposed lineup. |
| D23 | Classes | 10: Knight, Brute, Duelist, Scholar, Cleric, Spearman, Hunter, Nobody, Berserker, Occultist. | Owner's choice. |
| D24 | Roster | 8 enemy types per zone (64 total). Each generated zone instance uses a mix of **4 of its 8**, the same 4 throughout that zone. Plus Elite variants and 8 bosses. | Owner's choice. |
| D25 | Ranged weapons | Yes. Bows scale with Slicey, crossbows with Bonk. Unlimited ammo. | Owner's choice. |
| D26 | Build process | **No phases.** One complete build brief (`docs/BUILD_BRIEF.md`) that Opus executes top to bottom in one session; if a session ends early, the next session continues from `docs/PROGRESS.md`. | D27 | Git | Opus initialises the repo, commits at each internal milestone, creates the `DungeonJoe` GitHub repo with `gh`, pushes, and adds the Pages workflow. Owner sets Pages source to GitHub Actions. | Owner's choice. |
| D28 | Platforms | Desktop browsers only (Chrome, Edge, Firefox). 16:9 canvas letterboxed to the window, fullscreen button. No touch controls. | Owner's choice. |
| D29 | Debug menu | Ships hidden in the build. Ctrl+Shift+D opens a code prompt; the code is checked against a SHA-256 hash (never stored in plain text; the owner knows the code and it is in `docs/OWNER_PRIVATE.md`, which is git-ignored). Provides god mode, spawn enemy, jump to zone/boss, give item, set level, set NG+ cycle. A **seed** field at character creation. | Owner's choice. Client-side gating is not security; it only keeps the menu out of casual reach. |

| D31 | Joining | Guests join with the room code **only in the lobby** (before the host enters the world; the lobby is also where a host returns to invite more people, see GAME_DESIGN §12). Guests bring their own character from their own save and keep all Shards, loot, levels, spells and flask upgrades they earn. **Zone progress also carries to a guest's own world when it is the guest's next zone:** a boss beaten in the host's world counts for the guest if that zone number equals the guest's highest beaten zone + 1 (so a guest who has beaten zones 1–2 and helps beat 2 and 3 goes home with zone 3 beaten; a guest who has beaten only zone 1 and helps beat zone 4 gets nothing for it). | Owner's choice. |
| D32 | Tutorial | The first room of a new character's run is a safe training hall with sign posts (move, aim, attack, block, parry a dummy, dodge a red attack, step out of a blue piercing attack, two-hand, flask). | D33 | Co-op loot | Instanced per player: every enemy and chest rolls a separate drop for each player; you only see your own. | Owner's choice. |
| D34 | Controls | Rebindable keyboard/mouse and gamepad in Settings. Defaults in GAME_DESIGN.md §4. | Expected of the genre. |
| D35 | Equip load | **None.** Armor weight does not slow you or change the dodge. | Keeps the dodge rule (one dodge per 5 s) clean. |
| D36 | Language | English only in v1; all strings live in one table so a translation is possible later. | Scope. |
| D37 | Requirements | Every weapon, shield and casting tool has minimum stat requirements (Bonk / Slicey for weapons and shields; Brain for staffs; Prayer for talismans). Below the requirement a weapon still swings but deals 40% damage and its skills are locked; a shield below requirement guards at half value; a casting tool below requirement cannot cast. Every spell has its own Brain or Prayer requirement and cannot be slotted below it. Two-handing counts Bonk and Slicey at ×1.5 toward requirements (Souls rule). | Owner's instruction (2026-11-02). |
| D38 | Bonfire rest and flask | A bonfire heals you and refills the Thermos **only the first time you rest at it**. Later rests still respawn enemies, save, and open the menu, but restore nothing. **Dying refills the Thermos** (you respawn with full HP and full charges). There is **no other way** to get charges back: no drops, no shop item, no spell or affix (a data test enforces it). Raising the maximum (Joe's Lucky Socks) and changing the heal amount are allowed. | Owner's instruction (2026-11-02), corrected the same day: the proposed Soup Packet and Thermos Refill relief valves were rejected. |
| D39 | Review tuning | After an independent review of the package (2026-11-02): the level cost curve is `60 × 1.045^L + 15L` with Shard values ×5 so a zone clear funds its ten levels; a closed `EffectDef` / `PatternDef` vocabulary and a `utility` attack kind were added to DATA_MODEL; control effects (Freeze, Blind, Hexed, Silence, Root, Hold) and `statusImmune` were defined; every class kit was re-balanced to meet its own requirements; spells scale only with the casting tool (no caster-level scaling); one spell loadout per school; guest first-rest state is stored in the host world by playerId. | Fixes contradictions a builder would otherwise have to guess at. |
| D40 | Weapon scaling spread | Scaling grades are spread on purpose across the 16 weapon classes: main-stat scaling runs from **E to S** (Club E/–, Whip –/E … Greathammer S/–, Twin Daggers –/S); some weapons have no second stat (Greataxe A/–, Rapier –/A), some a little (Colossal Sword A/E, Battleaxe A/D, Katana D/A), and the true hybrids split it (Halberd A/C, Longsword B/B, Spear C/B, Twin Axes C/B, Mace B/E). | D61 | Snapshot format | Trystero data channels are reliable and ordered, so "unreliable" inputs and snapshots are sent reliably. Guests' Shardpiles from a wipe live in the host's world under their playerId. | NETCODE §6 authority split without a request/response round trip for every menu click. |
